# 趣味拼音磁鐵 App (Phonics App)

趣味拼音磁鐵 App 是一款使用 React 開發的拼音學習工具。孩子可以把字母磁鐵自由拼成單字，並即時看到拼音顏色與聽到發音。

## 已完成功能

- **雙模式切換**：可在自由拼字與單字解析兩種模式之間切換。
- **動態字母上色機制**：依紅 / 藍 / 黃 / Y 字母邏輯，為字母動態上色。
- **TTS 語音**：使用文字轉語音（TTS）朗讀拼出的單字。

## ⚠️ Known Issues（已知問題）

目前使用 Datamuse API 獲取 IPA 音標，但部分特定單字會發生顯示異常或抓不到資料的狀況。待後續修復 API 串接邏輯或引入備用方案。
